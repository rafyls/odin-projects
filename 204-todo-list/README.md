# TickList

This project (todo-list) is the fourth project of the [JavaScript course](https://www.theodinproject.com/paths/full-stack-javascript/courses/javascript).

This project aims to create a basic To-Do list web application named TickList.

A to-do is a task item that consists of the following:
  - a title,
  - a description,
  - a due date,
  - and a priority.

Task items are organized into projects. A project has a title and a list of to-dos.

By default, new task items are created in the default project named "Today".

Although mentioned in the [project specification](https://www.theodinproject.com/lessons/node-path-javascript-todo-list#assignment), this web application does not implement any persistence technique, and hence any data is lost after the page is reloaded.
